## 🔬 Highlights

### Feedback Control Systems (MATLAB)
Labs covering transfer functions, Bode plots, Root Locus, PID tuning, stability margins, and state-space representation across 9 labs and multiple assignments.

### Operating System (C/C++)
Lab experiments on process creation (`fork`), inter-process communication, semaphores, shared memory, and scheduling algorithms. Culminates in the **BMS Animated Ubuntu OS Project** — a full C++ OS simulation with animated terminal UI.

### NarutoCam 🍃
A fun personal project using OpenCV's Haar cascade classifier to do real-time face detection through a webcam, styled with Naruto-themed overlays.

### Full Stack PCB CNC Simulator
The most ambitious project — a full-stack app to simulate CNC PCB milling:
- **Backend**: Python FastAPI with vision processing (OpenCV), PDF parsing (PyMuPDF), AI diagnostics, and toolpath generation
- **Frontend**: React + Three.js 3D scene with animated CNC machine, HLS video streaming, and a real-time simulation timeline
