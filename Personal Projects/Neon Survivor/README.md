# Neon Survivor

A neon top-down arcade survival shooter that runs inside Google Colab (or any Jupyter notebook) with no installs. It is rendered with an HTML5 canvas through `IPython.display.HTML`.

## Run it
- **Notebook:** in Colab, go to *File → Upload notebook*, choose `Neon_Survivor.ipynb`, then run the cell.
- **Copy and paste:** paste the contents of `neon_survivor.py` into one Colab cell and run it.

Click the game once to give it keyboard focus, then click again to start.

## Controls
| Key | Action |
| --- | --- |
| WASD / Arrows | Move |
| Mouse | Aim |
| Hold click / F | Shoot / toggle auto-fire |
| Space / Shift | Dash (brief invincibility) |
| P | Pause |
| M | Mute |

## Features
- Six enemy types (chaser, dasher, shooter, splitter, mini, tank) and a boss every 5 waves
- XP crystals and level-ups where you pick 1 of 3 upgrades (multishot, pierce, crits, regen, orbit drones, and more)
- Particles, screen shake, damage numbers and synthesized sound effects
- High score saved in the browser
