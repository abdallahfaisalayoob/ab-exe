Q1 — IEEE 754 Floating-Point Arithmetic

(a) 11.75 + 4.25

1
Convert to binary
11.75 → 8+2+1+0.5+0.25 = 1011.11₂ 4.25 → 4+0.25 = 100.01₂
2
Normalize each
11.75 = 1.01111 × 2³ 4.25 = 1.00001 × 2²
3
Align exponents — make both exponent = 3
11.75 → 1.01111000 × 2³ (no change) 4.25 → 0.10000100 × 2³ (shift right by 1)
4
Add mantissas
1.01111000 + 0.10000100 ───────────── 10.00000000
5
Normalize result
10.00000000 = 1.00000000 × 2⁴
6
IEEE 754 single precision encoding
Sign = 0 (positive) Exponent = 4 + 127 = 131 = 10000011₂ Mantissa = 00000000000000000000000
✓ Final IEEE 754: 0 10000011 00000000000000000000000 Decimal result: 16.0
1.M format: (−1)⁰ × (1 + 0.0) × 2⁴ = 1.00000000000000000000000 × 2⁴

(b) 5.5 × 3.0

1
Convert to binary and normalize
5.5 = 101.1 = 1.011 × 2² 3.0 = 11.0 = 1.100 × 2¹
2
Multiply mantissas
1.011 × 1.100 ──────── 0000 0000 1011 1011 ──────── 10.00100 (= 10.001000)
3
Add exponents
Exponent = 2 + 1 = 3 Result so far: 10.001000 × 2³
4
Normalize
10.001000 × 2³ = 1.0001000 × 2⁴
5
IEEE 754 single precision encoding
Sign = 0 (positive) Exponent = 4 + 127 = 131 = 10000011₂ Mantissa = 00010000000000000000000 ↑ first bit after implicit 1 is at position M1 1.0001 → mantissa bits: 00010000000000000000000
✓ Final IEEE 754: 0 10000011 00010000000000000000000 Decimal result: 16.5
1.M format: (−1)⁰ × (1 + 0.0625) × 2⁴ = 1.00010000000000000000000 × 2⁴
💡 Tip when writing: always write the 23 mantissa bits carefully. Start with the bits after the implicit leading 1, then pad with zeros to 23 bits.

Q2 — Pipeline Hazards (No Forwarding)

Instruction sequence:

I1: LW x1, 0(x2) I2: ADD x3, x1, x4 ← needs x1 (written by I1) I3: OR x5, x3, x6 ← needs x3 (written by I2) I4: AND x7, x5, x8 ← needs x5 (written by I3) I5: SUB x9, x7, x10 ← needs x7 (written by I4)

(a) Identify All Data Hazards

All are RAW (Read After Write) hazards:

I1→I2: x1 I2→I3: x3 I3→I4: x5 I4→I5: x7

Total: 4 RAW hazards

(b) Number of Stalls (No Forwarding)

Without forwarding, data is only available after the WB (Write Back) stage. Each dependent instruction must wait 2 stall cycles per hazard.

4 hazards × 2 stalls each = 8 stall cycles total
⚠ Note: The assignment says "A stall is 1 clock cycle per hazard" — but the standard 5-stage pipeline requires 2 stalls per RAW hazard without forwarding. Write 8 stalls (2 per hazard) and note the standard assumption. If your instructor specifies 1 stall per hazard, answer is 4 stalls.

(c) Pipeline Diagram — No Forwarding (8 stalls)

Instruction C1C2C3C4C5 C6C7C8C9C10 C11C12C13C14C15C16C17
I1: LW x1,0(x2) IFIDEXMEMWB
I2: ADD x3,x1,x4 IFssID EXMEMWB
I3: OR x5,x3,x6 IF ssID EXMEMWB
I4: AND x7,x5,x8 IF ssID EXMEMWB
I5: SUB x9,x7,x10 IF ssID EXMEMWB

s = stall bubble (NOP inserted). Total cycles = 17. IF=Fetch, ID=Decode, EX=Execute, MEM=Memory, WB=WriteBack

Q3 — Pipeline Hazards (Full Forwarding)

(a) Number of Stalls With Forwarding

With full forwarding (EX→EX and MEM→EX paths available):

  • I1→I2 (LW x1 → ADD): This is a Load-Use hazard. LW result is only available after MEM stage. Even with forwarding, I2 must wait 1 stall.
  • I2→I3, I3→I4, I4→I5: All are R-type dependencies. EX→EX forwarding covers these with 0 stalls.
Total stalls = 1 (only the load-use hazard)

(b) Pipeline Diagram — Full Forwarding

I1: LW x1,0(x2) IFIDEXMEMWB
I2: ADD x3,x1,x4 IFsIDEX MEMWB
I3: OR x5,x3,x6 IFID EXMEMWB
I4: AND x7,x5,x8 IF IDEXMEMWB
I5: SUB x9,x7,x10 IFIDEXMEM

s = 1 stall (Load-Use hazard, I1→I2). Arrows show forwarding: MEM→EX for I1→I2, EX→EX for I2→I3, I3→I4, I4→I5.

Q4 — Binary Multiplication (Hardware Algorithm)

The 3-step hardware algorithm per iteration:

Step 1: Check LSB of Multiplier. If 1 → Add Multiplicand to Product. If 0 → No operation.

Step 2: Shift Multiplicand left by 1 bit.

Step 3: Shift Multiplier right by 1 bit.

Repeat for as many bits as the multiplier has.

Step 3: Shift Multiplier Right 0110 1000 0000 0100 0001
